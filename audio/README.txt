ENGLISH NOTEBOOK - ORIGINAL LISTENING AUDIO

The web no longer uses browser SpeechSynthesis / Google TTS.
Each listening test expects the real audio file for that test.

Recommended names:
U1-L1.mp3
U1-L2.mp3
U2-L1.mp3
U2-L2.mp3
...
U10-L1.mp3
U10-L2.mp3

Put the files in this /audio folder if you have the audio and have permission to use it.
Alternatively, use the file picker on the Listening setup screen; the selected file is played locally and is NOT uploaded to Firebase.

The exercise bank contains 6 blanks per test. The transcript/answers are shown only after submission.
